TWO RUNTIMES, ONE DEVICE

Native Android. Termux-powered tools.

The Android app hosts React Native and the real Hyperview renderer. A Node.js daemon runs natively in Termux, serves project screens, and streams file-change events. No Debian, proot, or virtual machine is required.

The app and Termux share Android loopback at http://127.0.0.1:4747: same-device connections need no port forwarding. Desktop development with a host daemon uses adb reverse instead; remove its port 4747 rule before testing Termux on the same device.

Project files stay in Termux's private home directory, outside the app's JavaScript runtime. Use a daemon token even on loopback. Full Termux package support starts at Android 7; Android background restrictions can still interrupt a session.

The current implementation provides native preview, connection controls, and request inspection. Reversible agent editing and validated preview publication are the next feature milestone; agent sessions remain planned.
